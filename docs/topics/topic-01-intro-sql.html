Intro to SQL

Use SQLite to define a small database, put data into it, and ask focused questions of the rows.

Back to course materials

Start with a table

The first exercise defines a pet table. A primary key identifies each row; not null prevents unnamed or unclassified pets from sneaking in through the side door.

create table pet
(
    id integer primary key autoincrement,
    name text not null,
    kind text not null,
    age integer,
    food text
);

Change data with SQL

insert, update, and delete change the database. The plural word in values matters; SQL is perfectly willing to point out a missing letter.

insert into pet (name, kind, age, food)
values ('Dorothy', 'dog', 11, 'peanut butter');

update pet set age = 12, food = 'pretzels'
where name = 'Dorothy';

Ask narrower questions

select reads data. Choose the columns you need, filter with where, and use order by when row order matters.

select kind, food
from pet
where age = 11
order by kind;
A table is data plus rules. SQL gives us a precise way to create both and to inspect the result.
