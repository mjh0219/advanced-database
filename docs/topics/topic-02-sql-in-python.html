SQL in Python

Python's sqlite3 module lets a program create tables, run queries, and turn result rows into ordinary Python data.

Back to course materials

Open a connection

A connection is the program's handle on a database file. It stays open while the program issues statements and commits completed changes.

import sqlite3

connection = sqlite3.connect("pets.db")
connection.execute("drop table if exists pet")
connection.commit()

Pass values as parameters

Use placeholders instead of building SQL strings by hand. The database driver handles the data values separately from the SQL command.

connection.execute(
    "insert into pet (name, kind, age, food) values (?, ?, ?, ?)",
    ("Dorothy", "dog", 11, "peanut butter"),
)
connection.commit()

Read rows and handle errors

A cursor provides rows from a query. Database operations can fail, so the example catches sqlite3.Error and keeps the failure visible instead of pretending the table name was fine all along.

cursor = connection.execute("select * from pet")
rows = cursor.fetchall()

try:
    connection.execute("insert into petz (name) values (?)", ("Sandy",))
except sqlite3.Error as error:
    print("Caught sqlite error:", error)
The SQL has not changed. Python supplies the control flow, values, and error handling around it.
